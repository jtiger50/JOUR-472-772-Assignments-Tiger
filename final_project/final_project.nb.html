Limitations/challenges so far are that coverage as a whole is pretty good everywhere at this point, so we have to mainly look at the highest speed of mobile coverage, since that is not yet available everywhere. Our broader starting questions about coverage will have to be applied to questions about higher-speed coverage. Also, another challenge we have run into so far is that a lot of the findings we were originally interested in will have very obvious conclusions, like the more populated ares are of course going to have better coverage. That wouldn’t make for a very good story. We’re going to have to get a bit more creative with how we use the data and where we look.
